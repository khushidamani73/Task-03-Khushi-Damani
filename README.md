#  ATM Interface System (Java)

---

##  Overview

The ATM Interface System is a console-based Java application that simulates real-world ATM operations. It is built using Object-Oriented Programming (OOP) principles and focuses on secure and structured handling of bank account operations.

This project is ideal for beginners to understand how classes interact in a real-life system.

---

##  Features

- Create bank account with initial balance  
- Check account balance  
- Deposit money securely  
- Withdraw money with validation  
- Prevent invalid transactions (negative amount / insufficient balance)  
- Interactive menu-driven system  

---

##  Key Concepts Used

- Encapsulation (private data with public methods)  
- Classes & Objects interaction  
- Constructors  
- Conditional statements (if-else)  
- Switch-case logic  
- Loops (do-while)  
- User input handling using Scanner
